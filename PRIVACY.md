# Privacy policy

BOAR MD Preview renders Markdown files in your browser. This page says what it touches.

**What it reads.** Only the text of a Markdown page you open: a local file (`file:///…/*.md`) or a raw `.md` / `.markdown` file on the web, and only when the browser shows it as plain text. It never runs on other pages.

**What it stores.** In your browser's extension storage: your theme, text size, whether live reload is on, and the list of websites you chose to always preview. Nothing else.

**What it sends.** Nothing. The extension makes no network requests, has no analytics and no tracking, and shares no data with anyone. Images that a Markdown file links to are loaded by the page, as they would be on any website.

**Untrusted files.** Markdown from the web may be hostile. Raw HTML in it is shown as text and never run, and links or images with unsafe addresses (such as `javascript:` or `data:text/html`) are not made clickable.

**Removing it.** Uninstalling the extension deletes its stored settings.

Questions: open an issue on the project's GitHub repository.
